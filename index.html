COMMENT JOUER

1. SE DÉPLACERAvancer / reculer, Haut pour sauter, Bas pour s'accroupir. Double appui sur une direction : dash.
2. FRAPPERPoing = rapide, Pied = puissant. En l'air, ils deviennent des attaques plongeantes à bloquer debout.
3. SE DÉFENDREGarde = bloquer. Garde + Bas pour les coups bas (balayages). Les coups aériens se bloquent debout.
4. PROJETERPoing + Pied tout près : projection imparable. Appuyez aussi sur Poing + Pied quand on vous attrape pour vous libérer.
5. ENCHAÎNERUn Poing qui touche peut enchaîner un Pied ou être annulé dans un coup spécial (ex : P puis ↓ → P).
6. SUPERLa jauge bleue se remplit en frappant et en encaissant. Pleine : ↓ → ↓ → + Poing. Chaque perso a la sienne.

Les coups spéciaux de chaque combattant sont affichés à la sélection et dans le menu pause.
